## 목적

현실에서는 한 장의 사진에 여러 음식이 함께 있는 경우가 많습니다 (예: "밥 + 국 + 반찬"). 요구사항 5.1에서 명시했듯이, 이 경우 "여러 음식을 합산한 하나의 칼로리 값"으로 처리해야 합니다. 즉, Notion에 기록할 때 "밥 + 국 + 반찬 (칼로리 합계)"로 한 줄에 저장된다는 뜻입니다.

## 쉬운 설명

예를 들어 점심을 먹을 때:
- 밥: 200kcal
- 국: 150kcal  
- 반찬 몇 가지: 250kcal
- 총합: 600kcal

한 장의 사진에 이 모든 것이 담겨 있으면, Notion에 "밥 + 국 + 반찬" 이렇게 메뉴명을 합치고, 칼로리는 600으로 기록합니다. 끼니 단위로 여러 줄을 만들지 않습니다.

## 필요한 입력

- P2.1 (비전 모델 API 연동) 완료 상태
- AI가 여러 음식을 어떻게 응답하는지 형식 정의 (예: `[{name: "밥", cal: 200}, {name: "국", cal: 150}, ...]`)

## 결과물

- 여러 음식 항목을 받아서 합산하는 함수:
```javascript
function aggregateMultipleFoods(foodItems) {
  const combinedName = foodItems.map(f => f.name).join(' + ');
  const totalCalories = foodItems.reduce((sum, f) => sum + f.calories, 0);
  return { menu: combinedName, calories: totalCalories };
}
```
- 테스트: 여러 음식이 포함된 사진으로 정확히 합산되는지 확인

## 선행 작업

**P2.1** (비전 모델 API 연동): AI 응답을 받아야 합산 처리를 할 수 있습니다.

## 수행 순서

1. P2.1 API 응답 형식 확인 (여러 음식이 배열인지, 문자열인지 등)
2. 음식명 합치는 로직 작성 (join, 구분자 선택 등)
3. 칼로리 합산 로직 작성 (reduce, sum 등)
4. 여러 음식 사진으로 테스트 (예: 밥/국/반찬이 함께 있는 사진)
5. 결과가 Notion 기록 형식과 일치하는지 확인

## done_when 확인 방법

- 여러 음식이 포함된 테스트 사진에서:
  - 메뉴명이 " + "로 구분되어 합쳐짐 (예: "밥 + 국 + 반찬")
  - 칼로리가 정확히 합산됨 (예: 200 + 150 + 250 = 600)
  - 결과가 JSON 또는 데이터 객체로 반환됨

## 확인 질문

1. 음식명 구분자는 " + "가 맞습니까? 다른 형식을 선호합니까?
2. AI 응답에서 음식명에 이미 "+"가 포함되어 있는 경우는 어떻게 처리할 예정입니까?
3. 칼로리가 실수(float)일 수 있습니까? 정수로 반올림할 예정입니까?
