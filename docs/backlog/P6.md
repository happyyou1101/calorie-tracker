## 목적

지금까지 각 기능을 따로 만들고 테스트했습니다. 하지만 실제 사용 관점에서 전체 워크플로우가 정상 작동하는지 검증해야 합니다 (요구사항 4).

"사진 촬영 → 공유 → AI 추정 → Notion 기록 → 하루 총합 갱신 → (초과 시) 알림" 이 모든 과정이 매끄럽게 작동하는지 확인합니다.

## 쉬운 설명

마치 새 휴대폰을 샀을 때 모든 기능이 제대로 작동하는지 테스트하는 것처럼, 우리 앱도 실제 사용 시나리오로 전체 흐름을 테스트합니다.

테스트 시나리오:
1. 아침: 휴대폰으로 조식 사진 촬영 → 앱으로 공유 → Notion 기록 확인
2. 점심: 조식 사진 촬영 → 공유 → Notion에 두 번째 줄 추가, 하루 총합 갱신 확인
3. 저녁: 저녁 사진 촬영 → 공유 → 목표 초과 시 알림 수신 확인
4. 추가: 수동 입력으로 간식 추가 → 하루 총합 재계산
5. 수정: Notion에서 메뉴명 수정 → 앱에서 반영 확인

## 필요한 입력

- P1, P2, P3, P4, P5 모든 기능이 완료된 상태
- 실제 안드로이드 기기 또는 에뮬레이터
- 테스트할 음식 사진 여러 장
- 실제 Notion 데이터베이스 (테스트 데이터 입력 가능 상태)

## 결과물

- 엔드투엔드 테스트 통과 기록
- 전체 워크플로우가 정상 작동하는 증거 (스크린샷, 로그 등)
- 발견된 버그 목록 및 수정 사항

## 선행 작업

**P1** (PWA 공유 대상): 앱이 설치 가능해야 함
**P2** (AI 추정): 사진을 받아 추정할 수 있어야 함
**P3** (Notion 기록): Notion에 기록할 수 있어야 함
**P4** (목표 초과 알림): 알림이 작동해야 함
**P5** (수동 입력 및 수정): 수동 입력과 수정이 가능해야 함

## 수행 순서

1. 테스트 계획 작성 (위의 5가지 시나리오)
2. 실기기에서 앱 설치
3. 각 시나리오 실행
4. Notion에서 데이터 확인
5. 목표 초과 알림 확인
6. 발견된 문제 기록
7. 필요시 버그 수정 및 재테스트

## done_when 확인 방법

- P6.1 (실사용 E2E 시나리오 실행)이 완료됨
- 모든 주요 기능이 정상 작동함
- 발견된 버그가 모두 수정됨
