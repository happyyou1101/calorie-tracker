# P4 — 목표 칼로리 설정 및 초과 알림

## 목적

칼로리를 기록하는 것만으로는 충분하지 않습니다. 사용자는 "오늘 1500칼로리까지만 먹기"라는 목표를 설정하고, 그것을 초과하면 알림을 받기를 원합니다 (요구사항 5.5). 이 작업은 목표 칼로리를 설정하고, 초과하는 순간을 감지하며, 사용자에게 알림을 보내는 전체 과정입니다.

## 쉬운 설명

다이어트를 할 때 "오늘은 1500칼로리만 먹겠다"고 다짐합니다. 그런데 계속 먹다가 1500을 넘으면 "어? 목표를 넘었네"라고 깨닫습니다.

우리 앱이 하는 일:
1. **목표 설정**: 사용자가 앱 설정에서 "목표: 1500kcal"이라고 입력 (처음엔 기본값 1500)
2. **목표 초과 감지**: 누적 칼로리가 1500을 넘는 순간 감지
3. **알림 발송**: "목표를 초과했어요!" 하고 사용자의 휴대폰에 알림 전송

## 필요한 입력

- P3 (Notion 기록 및 하루 총합) 완료 상태
- 목표 칼로리의 기본값 (요구사항 5.5: 1500kcal)
- 알림 방식 결정 (웹 푸시 알림, 이메일, 기타)

## 결과물

- 앱 설정 화면에서 목표 칼로리 입력/수정 가능
- 목표값이 로컬 저장소(localStorage)에 저장되어 앱 재시작 후에도 유지
- 하루 누적 칼로리가 목표를 초과하는 순간 감지하는 로직
- 초과 시 사용자의 휴대폰에 푸시 알림 발송
- 테스트: 초과 시나리오에서 실제 알림 수신 확인

## 선행 작업

**P3** (Notion 기록 연동 및 하루 총합 재계산): 하루 총합 값이 필요합니다.

## 수행 순서

1. **목표 칼로리 저장소 구현** (P4.1): UI와 localStorage 연동
2. **초과 감지 로직** (P4.2): 누적값과 목표값 비교
3. **알림 발송** (P4.3): 웹 푸시 등으로 사용자에게 전달

## done_when 확인 방법

- 앱 설정 화면에서 목표값을 변경했을 때 저장되고 재시작 후에도 유지됨
- 목표값을 초과하는 순간 알림이 발송됨
- 알림은 정확히 한 번만 발송됨 (초과한 후 또 다른 음식을 추가해도 중복 알림 없음)
- 실제 안드로이드 폰에서 알림 수신 확인 가능

## 확인 질문

1. 기본 목표값을 정말 1500kcal로 할 건가요?
2. 알림은 웹 푸시(Web Push)를 사용할 예정입니까? 아니면 다른 방식(이메일, SMS 등)?
3. 목표를 초과한 후 음식을 더 추가했을 때, 알림을 다시 보낼 건가요? (예: 500초과, 1000초과 등 단계별)
   - 아니면 하루에 한 번만 보낼 건가요?
4. 목표값은 매일 같은가요? 아니면 요일마다 다를 수 있나요?
