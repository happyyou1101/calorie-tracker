# P1.4 — 실기기 공유하기 목록 노출 확인

> 이 문서는 설명용입니다. 이 문서 작성 완료가 P1.4의 개발 완료를 뜻하지 않습니다.
> 개발 완료 여부는 backlog.json의 status 필드(CLI로 조회)로만 판단하세요.
> 기준 버전(source_sha256): 1105d02dad40e288cb774f5f37c661ea4d20d12d5e1f8caf1bc663856848a36c

## 목적

P1.1~P1.3까지 구현한 것들이 실제로 작동하는지 실기기에서 검증해야 합니다. 특히 "공유하기" 목록에 앱이 나타나고, 사진을 공유했을 때 앱이 제대로 받는지 확인하는 것이 핵심입니다. 이는 순수하게 검증(테스트) 작업입니다.

## 쉬운 설명

지금까지 한 일들이 모두 설정과 코드입니다. 하지만 실제로 안드로이드 폰에서 사진을 공유했을 때 이 앱이 목록에 나타나고 제대로 동작하는지 확인해야 합니다.

이 작업은:
1. 실제 안드로이드 폰(또는 에뮬레이터)을 준비합니다
2. 이 앱을 홈 화면에 추가합니다
3. 갤러리 앱에서 사진을 선택합니다
4. "공유하기" 버튼을 눌렀을 때 이 앱이 목록에 있는지 확인합니다
5. 이 앱을 선택해서 사진을 공유합니다
6. 앱이 제대로 받았는지 확인합니다

## 필요한 입력

- P1.2 (Service Worker 등록) 완료 후 홈 화면에 앱이 설치된 상태
- P1.3 (공유 인텐트 수신 엔드포인트) 완료된 상태
- 실제 안드로이드 기기 (또는 Android Studio 에뮬레이터)
- 테스트할 사진 파일

## 결과물

- 실기기 공유하기 목록에 앱 이름이 나타남
- 앱이 사진을 수신했다는 것을 확인할 수 있는 로그/메시지
- 테스트 결과 문서 (실행 날짜, 테스트 이미지 정보, 통과/실패)

## 선행 작업

**P1.2** (Service Worker 등록 및 홈 화면 추가): 앱이 홈 화면에 설치되어야 테스트할 수 있습니다.

**P1.3** (공유 인텐트 수신 엔드포인트): 엔드포인트가 구현되어야 사진을 받을 수 있습니다.

## 수행 순서

1. 실제 안드로이드 기기(또는 에뮬레이터)를 준비합니다
2. 크롬 브라우저에서 배포된 앱 URL 접속
3. "홈 화면에 추가" 프롬프트에서 "추가" 선택해 앱 설치
4. 홈 화면에서 앱 아이콘을 확인합니다
5. 갤러리 앱 또는 카메라 앱 실행
6. 사진 선택 → "공유" 버튼 클릭
7. 공유 대상 목록에서 이 앱이 나타나는지 확인
8. 앱을 선택하면 앱이 실행되고 사진 수신 확인
9. 개발자 도구/로그에서 사진 수신 기록 확인

## done_when 확인 방법

- 실제 안드로이드 기기의 갤러리 "공유하기" 메뉴에 이 앱이 나타남 (카카오톡, 문자 등과 함께)
- 앱을 선택했을 때 앱이 실행됨
- 앱의 로그/메시지(예: console.log, 화면 표시)에서 사진 수신이 기록됨
- 여러 번 반복해도 일관되게 작동함

## 확인 질문

1. 실제 안드로이드 기기가 있습니까? 없으면 Android Studio 에뮬레이터를 사용할 예정입니까?
2. 테스트할 사진은 준비했습니까? (일반적인 음식 사진 또는 테스트용 이미지)
3. 공유 시 앱이 어떻게 반응하기를 원합니까? (바로 AI 처리 진행, 확인 화면 표시, 등)
