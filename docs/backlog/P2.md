# P2 — 사진 → 칼로리 추정 (AI 비전 연동)

## 목적

이 시스템의 핵심은 사진을 받아서 AI 비전 모델에 전달하고, AI가 그 사진에 있는 음식을 인식해 메뉴명과 칼로리를 추정하는 것입니다 (요구사항 5.1). 이 작업에서는 AI 비전 API와의 연동, 여러 음식이 섞여 있을 때의 합산 처리, 그리고 AI가 음식을 인식하지 못했을 때의 처리를 구현합니다.

## 쉬운 설명

사진을 찍었습니다. 이제 그 사진을 AI에게 보여주고 "이게 무슨 음식이고 칼로리는 얼마인가요?"라고 묻습니다. AI가 답해줍니다: "이것은 돈까스와 밥이고, 대략 800칼로리입니다."

이 작업에서 하는 일:
1. **AI와의 통신**: 사진을 OpenAI, Google Cloud Vision 같은 AI 서비스로 보냅니다
2. **응답 해석**: AI가 주는 답을 정리해서 메뉴명과 칼로리를 추출합니다
3. **여러 음식 합산**: 한 사진에 여러 음식이 있으면 모두 합쳐서 하나의 칼로리 값으로 만듭니다
4. **실패 처리**: 음식이 인식되지 않는 경우(빈 사진, 음식이 아닌 물체 등) 대처합니다

## 필요한 입력

- P0 (프로젝트 기반 구축): 특히 P0.2 (API 키 관리)가 완료된 상태
- AI 비전 API 선택 및 API 키 확보 (예: OpenAI API, Google Cloud Vision, Claude Vision 등)
- 테스트용 음식 사진 여러 장

## 결과물

- AI 비전 API를 호출하는 함수 (예: `estimateCaloriesFromImage(imageData)`)
- 함수 반환 예시:
```json
{
  "menuName": "돈까스 + 밥",
  "calories": 800,
  "confidence": "medium"
}
```
- 에러 처리: AI가 음식을 인식하지 못했을 때의 응답
- 테스트: 여러 사진으로 추정값 확인 가능

## 선행 작업

**P0** (프로젝트 기반 구축): API 키 관리 인프라가 필요합니다.

## 수행 순서

1. **AI 비전 API 선택**: OpenAI, Google Cloud Vision, Claude, 기타 중 결정
2. **기본 API 호출 코드 작성** (P2.1): 이미지를 API로 보내고 응답 받기
3. **응답 파싱**: API 응답에서 음식명과 칼로리 추출
4. **여러 음식 합산 처리** (P2.2): "A + B" 형식으로 메뉴명 합치고 칼로리 합산
5. **실패 케이스 처리** (P2.3): 인식 실패 시 사용자에게 알리거나 수동 입력 유도

## done_when 확인 방법

- 테스트 사진 3장 이상을 API로 보내서 음식명 + 칼로리 추정값이 반환됨
- 로그에서 추정값이 합리적인지 확인 (예: 밥 한 공기는 150-200kcal)
- 여러 음식이 있는 사진에서 메뉴가 합쳐져서("음식1 + 음식2") 표시되고 칼로리가 합산됨
- AI 인식 실패 케이스(예: 빈 사진)도 에러 없이 처리됨
