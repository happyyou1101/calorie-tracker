# P1 — PWA 공유 대상(Share Target) 구현

## 목적

이 앱의 핵심 사용 방식은 안드로이드 갤러리에서 사진을 촬영한 후 "공유하기" 버튼을 눌러 이 앱으로 바로 보내는 것입니다 (요구사항 4, 5.2). 따라서 안드로이드 OS의 "공유하기" 목록(카카오톡, 문자, 이메일 등과 함께)에 이 앱이 나타나야 하고, 사진을 받아 처리할 수 있어야 합니다.

## 쉬운 설명

일반적인 웹사이트는 주소를 입력해서 접속합니다. 하지만 PWA는 앱처럼 설치할 수 있고, 안드로이드 OS가 제공하는 "공유하기" 메뉴에도 나타날 수 있습니다.

이 작업에서 하는 일:
1. **Web App Manifest 설정**: 앱의 이름, 아이콘, "공유하기" 설정을 정의합니다
2. **Service Worker 등록**: 앱이 오프라인에서도 작동하고, 홈 화면에 추가 가능하게 합니다
3. **공유 인텐트 수신**: 사용자가 사진을 공유했을 때 앱이 그것을 받을 수 있도록 준비합니다
4. **실기기 테스트**: 실제 안드로이드 폰에서 "공유하기" 목록에 이 앱이 나타나는지 확인합니다

## 필요한 입력

- P0 (프로젝트 기반 구축)의 모든 하위 작업이 완료된 상태
- HTTPS로 배포된 웹앱 URL
- 앱의 이름, 아이콘 이미지 (선택사항이지만 추천)
- 실제 안드로이드 기기 또는 에뮬레이터

## 결과물

- Web App Manifest 파일 (`public/manifest.json`)
- Service Worker 파일 (`public/sw.js` 또는 유사)
- 공유 인텐트를 받아 처리하는 엔드포인트/페이지
- 실제 안드로이드 기기에서 공유하기 목록에 나타나는 앱

## 선행 작업

**P0** (프로젝트 기반 구축): HTTPS 배포 없이는 PWA 및 공유 기능이 작동하지 않습니다.

## 수행 순서

1. **Web App Manifest 작성**: `manifest.json` 파일에 `share_target` 객체 정의 (POST, image/\* accept)
2. **Service Worker 등록**: `sw.js` 파일 작성 및 앱 시작 시 등록
3. **A2HS(홈 화면에 추가) 확인**: 안드로이드 크롬에서 "설치" 프롬프트 표시 확인
4. **공유 인텐트 수신 엔드포인트**: 공유된 이미지 수신 및 처리할 페이지/API 개발
5. **실기기 설치 및 테스트**: 실제 휴대폰에서 설치 후 갤러리에서 사진 공유

## done_when 확인 방법

- 배포된 앱의 Manifest가 유효함 (웹 검증 도구 통과, 예: web.dev의 Lighthouse)
- 안드로이드 크롬의 "홈 화면에 추가" 프롬프트가 자동 표시됨
- 앱을 설치한 후 안드로이드 갤러리에서 사진을 "공유하기" 했을 때 이 앱이 목록에 나타남
- 공유 시 앱이 실행되고 사진을 수신함

## 확인 질문

1. 앱의 이름과 아이콘 이미지는 이미 준비되었습니까?
2. 안드로이드 크롬 버전은 최신인지 확인했습니까? (Share Target API는 최신 크롬에서만 지원)
3. 실기기가 없는 경우 에뮬레이터(Android Studio의 Android Emulator)를 사용할 계획입니까?
