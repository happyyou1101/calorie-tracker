## 목적

이 앱이 외부 서비스(AI 비전 모델, Notion)와 통신하려면 인증 정보(API 키, 토큰)가 필요합니다. 이러한 민감한 정보를 코드에 직접 넣으면 누구나 접근할 수 있게 되므로, 환경변수를 사용해 안전하게 분리하고 관리해야 합니다.

## 쉬운 설명

API 키는 금은보화 상자를 여는 열쇠와 같습니다. 이 열쇠를 보이는 곳에 두면 누구나 와서 상자를 열 수 있습니다.

우리가 할 일:
1. `.env` 파일이라는 숨겨진 파일을 만들어 API 키들을 거기에만 저장합니다
2. `.env` 파일은 `.gitignore`에 추가해 Git에 올라가지 않도록 막습니다 (저장소에 공개되지 않음)
3. 코드에서는 환경변수로 이 값들을 읽어옵니다
4. 실제로 API를 호출해 둘 다 정상 작동하는지 테스트합니다

## 필요한 입력

- P0.1에서 만든 웹앱 프로젝트가 로컬에서 실행 가능한 상태
- AI 비전 API 제공자로부터 받은 API 키 (예: OpenAI API 키)
- Notion Integration 토큰
- Notion 데이터베이스 ID

## 결과물

- 프로젝트 루트 디렉토리에 `.env` 파일 (예: `VITE_VISION_API_KEY=...`, `VITE_NOTION_TOKEN=...`, `VITE_NOTION_DB_ID=...`)
- `.gitignore`에 `.env` 항목 추가
- 환경변수 로드 및 두 API 모두 인증 테스트할 수 있는 간단한 코드 (테스트 스크립트 또는 개발 페이지)
- 실행 시 "두 API 모두 정상 응답" 메시지가 나타남

## 선행 작업

**P0.1** (웹앱 스택 초기화): 이 작업을 먼저 완료해야 환경변수 로드 기능을 추가할 수 있습니다.

## 수행 순서

1. 프로젝트 루트에 `.env.example` 파일 작성 (형식 예시, 실제 값 없이)
2. 프로젝트 루트에 `.env` 파일 작성 (실제 API 키 입력)
3. `.gitignore`에 `.env` 추가
4. 웹앱 코드에서 환경변수를 읽도록 구성 (프레임워크에 따라 다름, 예: Vite의 `import.meta.env`, CRA의 `process.env`)
5. AI 비전 API 테스트 코드 작성 및 실행 (간단한 호출 → 응답 확인)
6. Notion API 테스트 코드 작성 및 실행 (인증 및 DB 접근 확인)

## done_when 확인 방법

- `.env` 파일이 프로젝트 루트에 있고 (`.gitignore`에 등록됨)
- 테스트 스크립트/페이지를 실행했을 때 "AI 비전 API 인증 성공", "Notion API 인증 성공" 같은 메시지가 나타남
- 실제로 API 응답이 console.log 등으로 확인 가능함
- Git 상태에서 `.env` 파일이 Untracked 또는 무시됨 상태임
