## 목적

사진을 AI에게 보내 음식명과 칼로리를 추정받는 핵심 로직을 구현합니다. 이것은 P0.2에서 관리하던 API 키를 사용해 실제 API를 호출하고, 응답을 파싱해서 사용 가능한 형태(음식명 문자열, 칼로리 숫자)로 만드는 작업입니다.

## 쉬운 설명

마치 다음과 같습니다:
1. "여기 사진이 있어요" → 이미지 파일을 AI로 보냄
2. AI가 생각하고 답합니다: "돈까스와 밥이 보이고, 약 800칼로리 같아요"
3. 우리는 그 답을 정리합니다: `{ "menu": "돈까스 + 밥", "calories": 800 }`

이 작업은 1번과 2번 과정 + 답변을 정리하는 부분입니다.

## 필요한 입력

- P0.2 (API 키 관리) 완료 상태
- AI 비전 API 선택 및 API 키
- API 호출 라이브러리 (예: openai, google-cloud-vision 등 npm/pip 패키지)

## 결과물

- API 호출 함수 (예: `async function callVisionAPI(imageBuffer)`)
- 응답 파싱 로직:
```javascript
const response = await callVisionAPI(imageBuffer);
const menuName = response.foodItems.map(f => f.name).join(' + ');
const calories = response.foodItems.reduce((sum, f) => sum + f.calories, 0);
```
- 테스트 케이스: 샘플 이미지 1~3장으로 API 호출 테스트 통과

## 선행 작업

**P0.2** (AI 비전 API·Notion API 시크릿 관리): API 키가 필요합니다.

## 수행 순서

1. AI 비전 API 라이브러리 설치 (npm install 또는 pip install)
2. API 호출 함수 작성 (이미지 버퍼/Base64를 입력으로 받음)
3. 환경변수에서 API 키 로드
4. API 요청 형식 구성 (이미지 전송, 프롬프트 등)
5. API 응답 수신 및 테스트
6. 응답에서 음식명, 칼로리 필드 추출하는 파싱 로직 작성
7. 테스트: 샘플 이미지로 응답 확인

## done_when 확인 방법

- 테스트 이미지 1장 이상을 함수에 전달했을 때 API 응답이 오류 없이 수신됨
- 응답에서 음식명(문자열)과 칼로리(숫자)를 안정적으로 파싱 가능
- console.log 또는 로그에서 추정값이 합리적인지 확인 (예: 밥은 150-200kcal)
- API 호출 횟수와 비용이 예상 범위 내인지 확인 (요구사항 관점에서)
