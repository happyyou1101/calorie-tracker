# P5.2 — 지난 날짜 수동 추가 시 하루 총합 재계산

## 목적

P5.1에서 과거 날짜에 음식을 추가했을 때, 그 날짜의 하루 총합이 다시 계산되어야 합니다 (요구사항 5.6). 마치 "어제 빼먹은 음식을 오늘 기록했는데, 어제의 총합이 정정된다"는 뜻입니다.

## 쉬운 설명

예를 들어:
- 월요일: 돈까스 600kcal, 총합 600
- 화요일 오후: "어, 월요일에 간식을 빼먹었네" → 간식 200kcal 추가 입력
- 결과: 월요일의 총합이 600 → 800으로 자동 갱신됨

## 필요한 입력

- P5.1 (수동 입력 폼) 완료 상태
- P3.3 (하루 총합 재계산 로직) 완료 상태

## 결과물

- 수동 입력 후 호출될 함수:
```javascript
async function onManualEntryAdded(date) {
  // date 날짜의 모든 행을 쿼리
  // 칼로리 합산
  // 모든 행의 "하루총합" 필드 업데이트
}
```
- 테스트: 과거 날짜에 항목을 추가했을 때 그 날짜의 총합이 갱신되는지 확인

## 선행 작업

**P5.1** (수동 입력 폼): 수동 입력이 가능해야 합니다.

**P3.3** (하루 총합 재계산): 재계산 로직이 필요합니다.

## 수행 순서

1. P5.1의 폼 제출 핸들러에서 날짜 정보 전달받기
2. 해당 날짜의 모든 행을 Notion에서 쿼리 (filter by Date)
3. 칼로리 합산
4. 모든 행의 "하루총합" 필드 업데이트 (또는 별도 요약 행 업데이트)
5. 테스트: 여러 과거 날짜에 항목 추가

## done_when 확인 방법

- 과거 날짜에 항목을 추가한 후 Notion을 새로고침하면 그 날짜의 총합이 변경되어 있음
- 계산이 정확함 (모든 행의 칼로리가 올바르게 합산됨)
- 다른 날짜의 데이터는 영향을 받지 않음

## 확인 질문

1. 과거 날짜에 항목을 추가했을 때, 오늘의 총합(현재 하루 총합)에도 영향을 주나요?
   - 예: 어제 200kcal 추가 → 오늘 총합은 변하지 않아야 함
2. 모든 행의 "하루총합" 필드를 업데이트할 건가요? (모두 같은 값)
   - 아니면 별도의 "요약" 행만 업데이트할 건가요?
