# P4.1 — 목표 칼로리 설정 UI/저장

> 이 문서는 설명용입니다. 이 문서 작성 완료가 P4.1의 개발 완료를 뜻하지 않습니다.

## 목적

사용자가 목표 칼로리를 설정하고 수정할 수 있는 인터페이스를 제공해야 합니다. 또한 설정값이 앱 재시작 후에도 유지되어야 합니다 (요구사항 5.5).

## 쉬운 설명

앱의 설정 화면에서:
1. "목표 칼로리" 입력 필드가 있습니다 (초기값: 1500)
2. 사용자가 새 값을 입력하면 저장됩니다
3. 앱을 껐다 켜도 그 값이 유지됩니다 (마치 휴대폰 설정처럼)

## 필요한 입력

- P0.1 (웹앱 스택) 완료 상태
- UI 라이브러리 또는 프레임워크 (React, Vue 등)
- localStorage 또는 IndexedDB 같은 클라이언트 저장소 결정

## 결과물

- 설정 페이지/화면 (또는 모달)
- 목표 칼로리 입력 필드 (초기값: 1500)
- "저장" 버튼
- localStorage (또는 IndexedDB)에 값 저장
- 앱 로드 시 저장된 값 복원

## 선행 작업

**P0.1** (웹앱 스택 초기화): UI 프레임워크 필요

## 수행 순서

1. 설정 페이지/컴포넌트 생성
2. 목표 칼로리 입력 필드 추가 (숫자만 입력 가능하도록 제약)
3. "저장" 버튼 클릭 시 localStorage에 저장하는 로직 작성
4. 앱 초기화 시 localStorage에서 값을 읽어오는 로직 작성
5. 값이 없으면 기본값 1500 사용
6. UI 테스트: 입력 → 저장 → 앱 재시작 → 값 유지 확인

## done_when 확인 방법

- 설정 화면에서 목표값 입력/수정 가능
- 값을 변경하고 저장했을 때 "저장됨" 메시지 표시
- 앱을 종료 후 다시 시작했을 때 수정한 값이 그대로 표시됨
- 처음 사용 시 기본값 1500이 표시됨
- 입력 필드가 숫자만 받도록 제약됨 (예: "abc" 입력 불가)

## 확인 질문

1. 목표값의 최소/최대값에 제약이 있습니까? (예: 500~5000kcal 범위만 허용)
2. 저장소는 localStorage로 충분합니까, 아니면 더 많은 데이터를 저장해야 해서 IndexedDB가 필요합니까?
3. 목표값은 텍스트 입력인가요, 아니면 슬라이더 같은 다른 UI 컴포넌트인가요?
