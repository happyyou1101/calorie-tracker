# P5 — 수동 입력 및 항목 수정 반영

## 목적

항상 사진을 찍을 수 있는 것은 아닙니다. 출장 중에 먹은 음식을 나중에 기억나서 기록하고 싶을 수도 있고, AI가 잘못 인식한 음식을 수정하고 싶을 수도 있습니다 (요구사항 5.6, 5.7). 이 작업은 사용자가 직접 메뉴와 칼로리를 입력하거나 수정할 수 있는 기능을 구현하는 것입니다.

## 쉬운 설명

상황:
1. **수동 입력**: 출장 중 점심을 먹었는데 사진을 못 찍었다. 저녁에 "아, 오늘 점심이 불고기 정식이었나, 칼로리 얼마였지?" 하고 생각해서 수동으로 입력한다.
2. **항목 수정**: AI가 "돈까스"를 "패스트푸드"라고 잘못 인식했다. Notion에서 직접 메뉴를 수정한다.

둘 다 이후에 하루 총합이 자동으로 재계산되어야 합니다.

## 필요한 입력

- P3 (Notion 기록) 완료 상태
- P5.1, P5.2, P5.3 하위 작업 완료 예정

## 결과물

- 수동 입력 폼 (날짜, 시간, 메뉴, 칼로리 입력 필드)
- Notion에서 직접 수정한 항목을 감지하고 반영하는 로직
- 지난 날짜에 항목을 추가/수정했을 때 해당 날짜의 총합 재계산

## 선행 작업

**P3** (Notion 기록 연동): Notion 접근 로직 필요

## 수행 순서

1. **수동 입력 폼 개발** (P5.1): UI와 Notion API 연동
2. **지난 날짜 총합 재계산** (P5.2): 과거 데이터도 총합 갱신
3. **Notion 직접 수정 반영** (P5.3): 웹훅 또는 폴링으로 변경 감지

## done_when 확인 방법

- 수동 입력으로 Notion에 새 행이 생성되고 하루 총합이 갱신됨
- 과거 날짜에 항목을 추가했을 때 그 날짜의 총합이 재계산됨
- Notion에서 직접 수정한 항목이 앱에 반영됨

## 확인 질문

1. 수동 입력 UI는 모달 팝업인가요, 아니면 별도 페이지인가요?
2. Notion 직접 수정 반영은 실시간(webhook)으로 할 건가요, 아니면 주기적(polling)으로 할 건가요?
3. 과거 날짜 선택 시 날짜 피커(date picker) 컴포넌트를 사용할 예정입니까?
