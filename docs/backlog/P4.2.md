# P4.2 — 하루 누적 칼로리 초과 감지

## 목적

하루 누적 칼로리가 목표를 초과하는 순간을 정확히 감지해야 합니다. "정확히 한 번" 감지해야 한다는 것이 중요합니다. 즉, 한 번 초과했으면 그 이후로는 초과 감지가 되지 않아야 합니다 (중복 알림 방지).

## 쉬운 설명

상황:
- 목표: 1500kcal
- 14:30 점심: 500kcal (누적: 500)
- 13:00 간식: 600kcal (누적: 1100)
- 19:00 저녁: 500kcal (누적: 1600) → **초과! 알림 발송**
- 20:00 디저트: 100kcal (누적: 1700) → 이미 초과했으므로 알림 **발송하지 않음**

이 로직을 구현하는 것이 이 작업입니다.

## 필요한 입력

- P4.1 (목표 칼로리 저장) 완료
- P3.3 (하루 총합 재계산) 완료, 현재 하루 누적값 접근 가능

## 결과물

- 초과 상태를 추적하는 변수 (예: `dailyLimitExceeded` 불린값)
- 초과 감지 함수:
```javascript
function checkCalorieExceeded(dailyTotal, goalCalorie) {
  const wasExceeded = localStorage.getItem('exceededToday') === 'true';
  const isExceeded = dailyTotal > goalCalorie;
  
  if (!wasExceeded && isExceeded) {
    // 처음 초과! 알림 발송
    return true;
  }
  return false;
}
```
- localStorage에 "오늘 초과했는지" 여부 저장
- 자정이 지나면 초과 상태 리셋

## 선행 작업

**P4.1** (목표 칼로리 설정 UI/저장): 목표값이 필요합니다.

**P3.3** (하루 총합 재계산): 현재 누적값이 필요합니다.

## 수행 순서

1. 초과 상태를 저장할 localStorage 키 정의 (예: "dailyExceededDate", "dailyExceeded")
2. 초과 감지 함수 작성 (이전 상태 vs 현재 상태 비교)
3. 매번 하루 총합이 업데이트될 때마다 함수 호출
4. 처음 초과 시에만 true 반환, 그 후로는 false
5. 자정(00:00)이 되면 초과 상태 리셋 (날짜 변경 감지)

## done_when 확인 방법

- 테스트로 누적값을 목표 이상으로 만들었을 때 함수가 true 반환
- 그 이후 또 다른 음식을 추가해도 함수가 false 반환 (중복 감지 없음)
- 자정을 넘으면 초과 상태가 리셋되고 새 날짜에서 다시 감지 가능
- 로그에서 "초과 감지됨" 메시지가 정확히 한 번만 나타남

## 확인 질문

1. 초과 상태를 localStorage에 저장할 때 날짜도 함께 저장해야 하나요? (자정 리셋을 위해)
2. "초과"의 정의가 `>` (초과)인가요, `>=` (이상)인가요?
3. 날짜 변경(자정)을 어떻게 감지할 예정입니까? (타이머, 페이지 로드 시 날짜 확인 등)
