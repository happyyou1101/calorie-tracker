## 목적

사진을 못 찍거나 AI 인식에 실패한 음식을 사용자가 직접 입력할 수 있는 폼을 제공해야 합니다 (요구사항 5.6). 이 폼을 통해 Notion에 새 행이 생성되어야 합니다.

## 쉬운 설명

앱에 "음식 추가" 버튼이 있습니다. 그것을 누르면:
- 날짜 선택 필드 (오늘 또는 과거 날짜)
- 시간 입력 필드 (예: 14:30)
- 메뉴 입력 필드 (예: "돈까스")
- 칼로리 입력 필드 (예: 800)
- "저장" 버튼

이런 폼이 나타나고, 사용자가 채워서 저장하면 Notion에 기록됩니다.

## 필요한 입력

- P3.2 (Notion API로 신규 행 생성) 완료 상태
- UI 프레임워크 (React, Vue 등)
- 날짜/시간 입력 컴포넌트 라이브러리

## 결과물

- 수동 입력 폼 UI:
  - "Date" 필드 (기본값: 오늘)
  - "Time" 필드 (기본값: 현재 시각, 또는 빈 칸)
  - "Menu" 필드 (텍스트 입력)
  - "Calories" 필드 (숫자 입력)
  - "Add" 또는 "Save" 버튼
- 입력 유효성 검사 (칼로리는 숫자만, 필수 필드 확인 등)
- 폼 제출 시 P3.2의 Notion 기록 함수 호출
- 성공 시 "저장되었습니다" 메시지 표시

## 선행 작업

**P3.2** (Notion API로 신규 행 생성): API 호출 함수 필요

## 수행 순서

1. 폼 컴포넌트 생성 (모달 또는 페이지)
2. 4개 필드 추가 (Date, Time, Menu, Calories)
3. 입력 유효성 검사 로직 작성
4. 폼 제출 시 Notion API 호출 (P3.2 함수)
5. 응답 처리 (성공/실패 메시지)
6. 폼 초기화 (저장 후 다시 비우기)

## done_when 확인 방법

- 폼을 열 수 있고 4개 필드를 모두 입력 가능
- 입력 검증: 칼로리에 숫자가 아닌 값 입력 불가
- 폼을 제출하면 Notion에 새 행이 생성됨
- 저장 후 폼이 초기화되고 "저장되었습니다" 메시지 표시
- 과거 날짜도 선택 가능 (날짜 피커에서)

2. 날짜와 시간 입력 방식은 어떻게 할 예정입니까?
   - 달력 피커 + 시간 선택기?
   - 텍스트 입력 (예: "2026-09-15 14:30")?
3. 칼로리 입력 시 범위 제약이 있습니까? (예: 0~5000kcal만 허용)
4. 메뉴 입력에 자동완성(autocomplete)이 필요합니까?
