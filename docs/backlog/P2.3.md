## 목적

모든 사진이 음식일 리 없습니다. 때로는:
- 빈 사진이 실수로 공유될 수 있습니다
- 음식이 아닌 물체(책, 스마트폰 등)가 사진에 담길 수 있습니다
- AI 모델이 무엇인지 정확히 파악하지 못할 수 있습니다

이럴 때 앱이 에러 없이 적절하게 대처해야 합니다 (요구사항 9 미확정 항목). 사용자에게 명확한 메시지를 표시하거나 수동 입력을 유도해야 합니다.

## 쉬운 설명

예를 들어 책장 사진을 실수로 공유했다면:
- 앱이 AI에 물어봅니다: "이게 뭐예요?"
- AI가 답합니다: "음식이 보이지 않습니다"
- 우리 앱이 사용자에게 알립니다: "음식이 인식되지 않습니다. 직접 입력하시겠어요?"

이렇게 사용자가 다음 단계(수동 입력)로 나아갈 수 있도록 안내하는 것이 목표입니다.

## 필요한 입력

- P2.1 (API 연동) 완료 상태
- 인식 실패의 정의 (어떤 조건을 "실패"로 볼 것인가)
  - 예: AI 신뢰도 낮음, "음식" 키워드 없음, 응답 파싱 실패 등
- 실패 시 처리 방식 결정 (스펙 §9 미확정)

## 결과물

- 인식 실패를 감지하는 로직:
```javascript
function isRecognitionFailed(response) {
  return !response.foodItems || response.foodItems.length === 0 
    || (response.confidence && response.confidence < threshold);
}
```
- 사용자 안내 메시지 (예: "음식이 인식되지 않았습니다. 수동 입력하시겠어요?")
- 수동 입력 폼으로의 자동 전환 또는 버튼 표시
- 테스트: 음식이 아닌 이미지(빈 사진, 책장 등)로 실패 처리 검증

## 선행 작업

**P2.1** (비전 모델 API 연동): API 응답을 받아야 실패 여부를 판단할 수 있습니다.

## 수행 순서

1. AI 인식 "실패" 조건 정의 (신뢰도 한계값, 응답 형식 등)
2. 실패 감지 함수 작성
3. 실패 시 사용자에게 보여줄 메시지/UI 디자인
4. 수동 입력 폼으로 유도하는 로직 구현 (P5.1과 연계)
5. 테스트: 음식이 아닌 사진(또는 빈 사진) 여러 장으로 테스트

## done_when 확인 방법

- 음식이 보이지 않거나 인식되지 않는 테스트 이미지를 전송했을 때:
  - 앱이 에러 없이 처리됨
  - 사용자에게 명확한 실패 메시지가 표시됨 (예: "음식이 인식되지 않았습니다")
  - 수동 입력 폼 또는 재촬영 옵션이 제시됨

## 확인 질문

1. 인식 "실패"를 어떻게 정의할 예정입니까?
   - AI의 신뢰도(confidence) 낮음?
   - 응답에 음식 항목이 없음?
   - API 호출 자체가 실패?
2. 실패 시 사용자 경험은 어떻게 할 예정입니까?
   - 에러 메시지만 표시?
   - 수동 입력 폼으로 자동 전환?
   - 재촬영 권유?
3. 실패해도 Notion에 기록할 건가요, 아니면 기록 전에 수동 입력을 강제할 건가요?
