## 목적

AI가 음식을 인식했으면 이제 그 결과를 Notion에 기록해야 합니다. Notion API를 사용해 데이터베이스에 새로운 행을 INSERT하는 작업입니다 (요구사항 5.3).

## 쉬운 설명

마치 엑셀 표에 새로운 행을 추가하는 것처럼, Notion 표에도 프로그래밍으로 새 행을 추가합니다:
1. AI 추정 결과를 변수에 저장: `{ date: "2026-09-15", time: "14:30", menu: "돈까스", calories: 800 }`
2. Notion API를 호출: "이 데이터를 DB에 추가해줘"
3. Notion이 응답: "추가했어요, 행 ID는 xyz"

이 작업은 이 과정을 코드로 구현하는 것입니다.

## 필요한 입력

- P3.1 (Notion DB 스키마 설계) 완료, Database ID 확보
- Notion API 토큰 (P0.2에서 이미 확보)
- Notion Node.js 라이브러리 (@notionhq/client 등)

## 결과물

- Notion API 호출 함수:
```javascript
async function createNotionRecord(date, time, menu, calories) {
  const response = await notion.pages.create({
    parent: { database_id: DB_ID },
    properties: {
      "Date": { date: { start: date } },
      "Time": { rich_text: [{ text: { content: time } }] },
      "Menu": { title: [{ text: { content: menu } }] },
      "Calories": { number: calories }
    }
  });
  return response.id;
}
```
- 테스트: 테스트 데이터로 Notion에 행이 생성되는지 확인
- 주의: 사진 파일은 저장하지 않음 (요구사항 5.3, 7)

## 선행 작업

**P3.1** (Notion DB 스키마 설계): Database ID 필요

## 수행 순서

1. Notion Node.js 라이브러리 설치 (`npm install @notionhq/client`)
2. Notion API 클라이언트 초기화 (토큰 사용)
3. 데이터베이스 ID 설정
4. API 호출 함수 작성 (date, time, menu, calories 파라미터)
5. Notion API 응답 형식 확인 및 파싱
6. 테스트 데이터로 함수 호출
7. Notion 웹사이트에서 행이 생성되었는지 확인

## done_when 확인 방법

- 함수를 호출했을 때 API 응답 상태가 200 (성공)
- Notion 웹사이트의 데이터베이스에 새 행이 실제로 나타남
- 행의 필드들이 올바르게 채워져 있음 (날짜, 시간, 메뉴, 칼로리)
- 테스트 데이터로 여러 행을 추가해도 중복 없이 정상 추가됨

## 확인 질문

1. 날짜 형식은 어떻게 할 예정입니까? (ISO 8601 형식 필수, 예: "2026-09-15")
2. 시간 형식은 어떻게 할 예정입니까? (텍스트 "HH:MM", 또는 "2026-09-15T14:30:00Z" ISO 형식)
3. "하루총합" 필드는 이 API 호출에서 입력할 건가요, 아니면 Notion의 자동 수식에 맡길 건가요?
4. 에러 발생 시 (예: 네트워크 오류, API 인증 실패) 어떻게 사용자에게 알릴 예정입니까?
