## 목적

이 프로젝트는 웹 앱(PWA, Progressive Web App)으로 만들어져야 합니다. 또한 AI 비전 모델과 Notion의 API를 사용하기 위해 여러 개의 API 키를 안전하게 관리해야 하고, 사용자의 안드로이드 폰에서 "공유하기" 기능을 사용하려면 HTTPS 프로토콜로 배포되어야 합니다. 따라서 프로젝트의 기본 인프라(웹앱 프레임워크, API 키 관리, 배포 파이프라인)를 먼저 준비하는 것이 필수입니다.

## 쉬운 설명

집에서 새로운 웹 사이트를 만들 때, 먼저 기초공사를 하는 것과 같습니다. 이 작업은 다음 세 가지를 준비하는 것입니다:

1. **웹앱의 기본 틀**: 리액트, Vue 같은 현대적인 도구를 사용해 웹사이트의 기본 구조를 만듭니다. 특히 이 앱은 안드로이드 폰에 설치 가능해야 하므로, PWA라는 특별한 기술 요구사항이 있습니다.

2. **민감한 정보(API 키) 숨기기**: 음식 사진을 AI에게 보내거나 Notion에 데이터를 저장할 때 필요한 "비밀 열쇠" 같은 것들입니다. 이것들이 인터넷에 공개되면 누구나 사용할 수 있게 되므로, 환경변수(`.env` 파일 같은 방식)로 안전하게 저장합니다.

3. **인터넷에 공개하기**: 여러분의 폰에서 접근할 수 있도록 웹사이트를 인터넷에 배포합니다. PWA가 제대로 작동하려면 반드시 HTTPS(안전한 인터넷 연결)로 배포되어야 합니다.

## 필요한 입력

- 웹앱을 만들기 위한 프레임워크 선택 (예: React, Vue, 순수 JavaScript 등)
- AI 비전 API 제공자의 API 키 (예: OpenAI Vision, Google Cloud Vision 등)
- Notion Integration 토큰과 Database ID
- 배포할 서버/플랫폼 (예: Vercel, Netlify, 자신의 서버 등)

## 결과물

- 웹앱 프로젝트 스캐폴드가 로컬에서 동작 가능한 상태
- `.env` 파일로 분리된 API 키 관리 체계
- HTTPS로 접근 가능한 배포 URL과 그 배포를 자동화하는 명령어/파이프라인 문서
